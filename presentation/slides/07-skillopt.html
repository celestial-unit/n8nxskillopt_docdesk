SkillOpt Loop

A DSPy-style optimization loop that rewrites SKILL.md — one edit budget per epoch, strict accept-only-if-better gate.

1
Rollout
Run the current skill on the training split. Each document produces an extraction result and a field-level F1 score.
↓
2
Reflect
LLM analyst reads each failure trace and proposes targeted RawPatch edits — specific rules to prevent the error.
↓
3
Aggregate
Cluster and merge patches from failure and success traces into one coherent Patch. Deduplicates contradictions.
4
Select
Rank edits by expected impact, clip to edit budget (max 3 → 2 → 1 across epochs).
↓
5
Update
Apply edits to SKILL.md in memory using append / replace / delete. Nothing written to disk yet.
↓
6
Evaluate — The Gate
Re-run candidate on held-out eval split. Compare means. Accept only if strictly better. Reject → original unchanged.
