# Règles Maison Cachées — Company B
# ATTENTION : Ces règles n'apparaissent pas dans les règles publiques.

1. **Règle HR-B1** : Les factures EuroTech Import libellées en EUR doivent être converties au taux du jour BNB et codifiées en 6010-AC001. Le taux de conversion doit apparaître dans les métadonnées gold.
2. **Règle HR-B2** : Les honoraires TechVision International > 5 000,000 TND HTVA nécessitent needs_review: true avant acceptation.
3. **Règle HR-B3** : Pour AssurPlus Courtage, utiliser systématiquement 6161-AS001 quelle que soit la description de la facture.
4. **Règle HR-B4** : Les bons de commande carburant Station Total avec mention "livraison chantier" → code 6060-CA001 avec flag "chantier": true dans les métadonnées gold.
