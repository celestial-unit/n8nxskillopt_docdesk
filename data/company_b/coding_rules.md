# Règles de Codification Comptable — Company B

## Règles générales

### Énergie
- Factures STEG (électricité, gaz) → code **6060-EN001** (TVA 19%)
- Factures SONEDE (eau) → code **6060-EA001** (TVA 7%)

### Télécommunications
- Factures Tunisie Telecom, Ooredoo, Orange → code **6261-TE001** (TVA 19%)

### Carburant
- Achats de carburant (Station Total) → code **6060-CA001** (TVA 13%)

### Services informatiques
- Prestations IT et maintenance → code **6170-IT001** (TVA 19%)
- Acquisition matériel informatique (amortissable) → code **6810-AM001** (exonéré TVA)

### Assurances
- Primes d'assurances (AssurPlus Courtage) → code **6161-AS001** (TVA 7%)

### Services bancaires
- Frais et commissions bancaires → code **6270-BK001** (TVA 13%)

### Timbre fiscal
- Toujours → code **6370-TF001** (exonéré TVA)

### Fournitures
- Monoprix, Carrefour (consommables bureau) → code **6060-FO001** (TVA 19%)

## Taux de TVA par catégorie
- 7% : eau (SONEDE), assurances
- 13% : carburant, services bancaires
- 19% : tout le reste (énergie STEG, télécom, IT, achats marchandises, etc.)
- 0% (exonéré) : timbre fiscal, salaires, cotisations, amortissements
