# Règles de Codification Comptable — Company A

## Règles générales

### Achats et charges d'exploitation
- Les achats de marchandises destinés à la revente → code **601000**
- Les achats de matières premières et consommables → code **602000**
- Les fournitures de bureau et petits matériels → code **606200**

### Énergie et services publics
- Toutes les factures STEG (électricité et gaz) → code **606100**
- Toutes les factures SONEDE (eau) → code **606100**

### Télécommunications
- Factures Tunisie Telecom, Ooredoo, Orange (téléphone, Internet) → code **626100**

### Carburant
- Achats de carburant (stations-service Total, Shell) → code **606300**

### Alimentaire et fournitures
- Achats Monoprix, Carrefour (fournitures, consommables) → code **606200**

### Services informatiques
- Prestations IT, maintenance informatique (InfoPro, SysTech, DataSys) → code **617000**

### Timbre fiscal
- La ligne timbre fiscal sur chaque document → code **637000**

## Taux de TVA
- TVA standard applicable : 19% sur toutes les lignes
- Le timbre fiscal est exonéré de TVA
